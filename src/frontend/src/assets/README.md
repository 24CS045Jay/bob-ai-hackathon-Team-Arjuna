# Tideline Assets Directory
### Governed by Section 4.7 (Real Video Hero Background Law)

For full-bleed video backgrounds in `OceanAnimation.jsx` and `LandingPage.jsx`:
Stock footage clips should be placed in `public/assets/video/`:

1. `public/assets/video/hero-ocean-aerial.mp4`:
   - Search term: `aerial ocean drone 4k` or `container ship at sea aerial`
   - Source library: Pexels Videos, Coverr, or Mixkit
   - Format: 1080p, H.264, 10–20s loop, compressed to <5MB
2. `public/assets/video/hero-container-port.webm`:
   - Search term: `cargo port cranes timelapse` or `container terminal aerial view`
   - Source library: Coverr or Pexels Videos
   - Format: 1080p WebM/MP4
3. `public/assets/video/hero-ocean-poster.jpg`:
   - Static still frame from the same video clip for zero-flash poster loading and `prefers-reduced-motion` accessibility.
